# Annuaire client/serveur Python

Consultation et administration d’un annuaire avec interfaces utilisateur et administrateur.

## Technologies

Python, Tkinter, TCP, JSON, SQLite.

## Installation et utilisation

Python 3.10 ou supérieur avec Tkinter. Depuis la racine : `python -m server.app`, puis dans un autre terminal `python -m clients.gui`. Définir `CAMPUS_ADMIN_PASSWORD` avant de démarrer.
